Bing Webmaster -automaattisync rajattiin ydindataan (`GetUserSites`, rank/query/page stats, crawl stats/issues); detail-metodit dokumentoitiin `BING-WEBMASTER-SYNC.md`:aan myohempaa erillistoteutusta varten.
